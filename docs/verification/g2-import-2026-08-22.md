  -dry-run -report /tmp/question-brain-g2-dry-run.json

The write run used the same root and produced an append-only import run:

  -report /tmp/question-brain-g2-full.json
```

```

Postgres evidence after the run:

```text
questions=1367 archived=0
question_locale: en=1368, ru=1020
placement_decision=1368
outbox_event=1368 pending
```

The importer records `import_run` and `import_item` rows. Re-running the same
root is idempotent; a missing source file is recorded as an archived question,
not deleted. A parse/read error is retained as an `invalid` item so it cannot
silently trigger archival of an existing card.
